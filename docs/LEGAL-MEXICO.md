# Consideraciones Legales para México

## Cumplimiento Normativo

- **Ley Federal de Protección de Datos Personales en Posesión de Particulares (LFPDPPP)**
- **Aviso de Privacidad** según INAI
- **Términos y Condiciones** específicos para México
- **Responsabilidad limitada**

## Términos de Uso

1. **Propiedad Legítima**: Solo dispositivos propios
2. **Autorización**: Permiso del propietario
3. **Uso Legal**: Prohibido fines ilegales
4. **Responsabilidad**: Usuario responsable
5. **Privacidad**: Datos retenidos 30 días max

**Usuarios responsables de cumplir leyes mexicanas.**
